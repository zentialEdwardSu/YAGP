# YAGP 示例 / Examples

## 中文

这些示例演示最近加入的能力。它们都是可选素材，不影响 YAGP 默认启动。

| 示例 | 演示内容 | 运行方式 | 素材 |
|---|---|---|---|
| [image](image/README.md) | PNG/JPG 静态图、alpha/hitbox、移动/变换/透明度、静态图禁用播放控制 | 添加 `pet.png`、`photo.jpg` | 项目生成 |
| [leader-follower](leader-follower/README.md) | compose 自动绑定、链式 `yagp.followers()`、follower 脚本停止/恢复 | 导入 `leader-follower/yagp.compose` | 用户提供的 GIF |
| [group](group/README.md) | `.compose` 分组导入、组隐藏/显示/移除、成员自身隐藏交互 | 导入 `group/yagp.compose` | 用户 GIF 副本 + 生成 PNG |

**填写模板：** 复制 [yagp.compose.sample](yagp.compose.sample) 到自己的分组目录，重命名为 `.compose` 后按注释修改；也可以直接使用托盘“分组 → 创建分组…”，在保存对话框中生成模板。分组导入只接受 `.compose` 文件；没有 compose 文件无法导入。

旧的 clip/事件测试已整体移到 [legacy-demo](legacy-demo/README.md)：`demo.lua`、`main.gif`、`walk.gif`、`sit.gif`、`look_*.gif`、`react.gif` 保持原文件名和相对路径，`demo.lua` 仍可直接运行。

## English

These examples demonstrate the recently added features. They are optional and
do not affect normal YAGP startup.

| Demo | Shows | How to run | Assets |
|---|---|---|---|
| [image](image/README.md) | PNG/JPG still images, alpha/hitbox, movement/transforms/opacity, disabled playback controls | Add `pet.png`, `photo.jpg` | generated by the project |
| [leader-follower](leader-follower/README.md) | automatic compose binding, chainable `yagp.followers()`, follower script stop/resume | Import `leader-follower/yagp.compose` | user-provided GIFs |
| [group](group/README.md) | `.compose` group import, group hide/show/remove, individual-vs-group hiding | Import `group/yagp.compose` | user GIF copies + generated PNG |

**Template:** copy [yagp.compose.sample](yagp.compose.sample) into your own group
directory, rename it to `.compose`, and edit the comments. Group import accepts
only `.compose` files; a folder without one cannot be imported.

The old clip/event test now lives in [legacy-demo](legacy-demo/README.md):
`demo.lua`, `main.gif`, `walk.gif`, `sit.gif`, `look_*.gif` and `react.gif` keep
their names and relative paths, so `demo.lua` still runs as before.
