# 图片示例 / Image demo

## 中文

把 `pet.png`、`photo.jpg` 作为静态桌宠：

- `pet.png`：带透明边的 PNG，演示 alpha、hitbox、移动、透明度和缩放/倾斜；
- `photo.jpg`：不透明 JPEG，演示旋转/移动，不依赖 alpha；
- `pet.lua` / `photo.lua`：脚本顶层会尝试调用 `yagp.play` / `yagp.clip`，并把返回的 `nil, err` 写入日志，说明静态图没有动画控制。之后只使用移动、变换、透明度和通知。

运行方式：

1. 托盘 →“添加媒体…”，选择这两张图；或运行
   `yagp.exe example\image\pet.png example\image\photo.jpg`。
2. 观察两张图移动/变换；右键菜单里的“暂停”对图片灰显。
3. 图片仍可缩放、色键、隐藏、分组和绑定脚本；`play`、`seek`、`clip`、`set_speed` 等接口返回“没有动画”。

素材由 `make_assets.py` 生成（Pillow），不是第三方图片；可按 MIT 许可使用。删除图片不会删除文件。

## English

Use `pet.png` and `photo.jpg` as still-image pets:

- `pet.png`: transparent PNG, showing alpha, hitbox, movement, opacity and scale/skew;
- `photo.jpg`: opaque JPEG, showing movement/rotation without alpha;
- `pet.lua` / `photo.lua`: at load time they try `yagp.play` / `yagp.clip` and log
  the returned `nil, err`, showing that still images have no animation controls.
  Afterwards they only use movement, transforms, opacity and notifications.

How to run:

1. Tray → "Add media…" and select both files, or run
   `yagp.exe example\image\pet.png example\image\photo.jpg`.
2. Watch them move and transform. The Pause menu item is greyed out for images.
3. Images still support scale, colour key, hiding, groups and scripts; `play`,
   `seek`, `clip`, `set_speed` and related calls report "no animation".

The assets are generated by `make_assets.py` with Pillow (not third-party art)
and are MIT-licensed with the project. Removing an overlay never deletes the
files.
